# HumanWriting
Replicated Human Typing Software

Current Features:
- Open any .txt file and replicate the typing
- file browser
- text preview
- replicate typos and correction of the typo
- Random pauses to replicate thought varying in length
- Press ESC to stop the writing
- Press P to pause typing
- Progress Bar with estimated time remaining
- Settings Menu With Changeable typing speed, typo chance and toggle of progress bar
- 5 second countdown before it begins typing
- completion popup with total time taken
- on the text preview make it count the words, characters and paragraphs
